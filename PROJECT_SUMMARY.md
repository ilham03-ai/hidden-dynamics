# Project Summary

`Hidden Dynamics` is a small world-model project built around a simple failure mode: the current observation is not enough to determine the future. The environment is a grid world where the agent has to remember whether it already triggered a hidden switch state before touching a beacon. I trained a PyTorch latent dynamics model to predict future observations and then checked whether the latent was actually carrying that hidden information, using rollout tests, probe heads, latent analysis, and counterfactual examples. The project works best as a compact testbed for state representation, not as a benchmark for scale.

What I like about this project is that the hidden dependency is easy to explain but still strong enough to force a real memory problem. The useful result is not just that the model gets decent MSE, but that the latent supports nontrivial hidden-state recovery and can distinguish counterfactual branches reasonably well. The weak point is that the model still struggles with confidence calibration and with harder counterfactuals from ambiguous mid-trajectory states.
